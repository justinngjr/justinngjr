## 🚀 Featured Project

### LunchPrep · TypeScript, Next.js, Gemini API
Categorises bank statements for [Lunch Money](https://lunchmoney.app) without exposing sensitive financial data.
- Statements are parsed and anonymised **in the browser**; only cleaned transaction descriptions reach the Gemini API
- Preprocessing rules, derived from hand analysis of real statements, strip noise and keep compact, high-signal context
- Categories are merged back into a Lunch Money-compatible CSV
